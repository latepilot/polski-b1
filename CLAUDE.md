# Polski B1 — правила работы с репозиторием

Приложение живёт на GitHub Pages: **https://latepilot.github.io/polski-b1/**
Запускается с айфона как PWA (Поделиться → «На экран Домой»). Сервер не нужен.

## Разделение ответственности — ВАЖНО

Над репозиторием работают двое. Чтобы не конфликтовать:

### Гермес (Telegram → словарь)
Трогает **только** `data/personal.js`.

Workflow: диктовка в Telegram → `~/hermes/notes/slowa.md` → парсинг → `data/personal.js` → push.

Формат файла менять нельзя, приложение на него завязано:
```js
let PERS_VOCAB = [
  {id: 0, pl: 'wybitny', ru: 'выдающийся'},
];
```
`id` уникальны и не переиспользуются, в конце файла — хелпер для следующего id.

### Claude Code (код и тренажёр)
Всё остальное: `index.html`, `egzamin.js`, `sw.js`, `data/gramatyka.js`,
`data/sluchanie.js`, `data/pisanie.js`, `data/decl.js`, `data/vocab.js`, иконки, манифест.

`data/personal.js` не редактировать — это территория Гермеса.

### Если случился конфликт
Файлы разные, git разведёт сам. При конфликте в `personal.js` — версия Гермеса
главнее, брать `--theirs`.

## Перед push

```bash
node --check egzamin.js && node --check sw.js
for f in data/*.js; do node --check "$f" || echo "СЛОМАН: $f"; done
```

Пуш идёт по отдельному ключу:
```bash
GIT_SSH_COMMAND="ssh -i ~/.ssh/github_polski_b1 -o IdentitiesOnly=yes" git push origin main
```

## Кеш

`sw.js` работает по схеме network-first: при интернете всегда свежая версия.
Если после правки на айфоне видна старая — закрыть приложение из многозадачности
и открыть заново.

При изменении списка файлов обновить `ZASOBY` и версию `CACHE` в `sw.js`.

## Генерация заданий

Пять типов из восьми собираются на лету (`data/generatory.js`): odmiana,
stopniowanie, czasy, tryby, przyimki. Около 1800 неповторяющихся заданий
против 59 статичных — иначе они заучиваются за неделю.

Правило: **формы никогда не выводятся алгоритмом.** Польское спряжение
слишком нерегулярное (biorę, jem, wiem, mogę), поэтому формы вписаны в банк
и проверены. Генератор только подбирает и комбинирует. Выводятся только
действительно регулярные вещи: условное наклонение (прошедшее + bym)
и сложное будущее (będę + инфинитив).

Дистракторы — всегда формы того же слова. Иначе задание проверяет знание
лексики, а не грамматики.

У каждого слова — свои предложения (`ZDANIA_*` в `generatory.js`), общие
шаблоны давали «uczy się najcieplej» и «Gdybym miał czas, wziąłbyś». И в
каждом задании ровно один верный ответ: лицо в скобках «(kupić — ja)»,
сигнал степени (bardzo / niż / ze wszystkich), неверные предлоги вписаны
вручную (`zle`). Перед добавлением проверь: не верен ли какой-то из
«неверных» вариантов (pod kinem, możesz, wasze, nie ma nic, ciebie).

При добавлении контекста для предлога указывать падеж прямо в записи:
`z` бывает и с Dopełniaczem («z pracy»), и с Narzędnikiem («z kolegą»),
и без явного падежа объяснение будет врать.

Глаголы помечены `nprz:true`, если непереходные — иначе шаблон
выдаёт «Wracajcie to razem».

## Навигация

Стрелка ← в шапке возвращает на предыдущий экран, домик — на главную.
Каждый экран в начале своей функции регистрируется через
`ekran(ключ, функция_перерисовки)` (index.html); в KURS, EGZ и SLOWNIK —
через их `wejdz()`. Новый экран без регистрации — стрелка с него уведёт
не туда. Повторный вызов с тем же ключом — обновление, а не новый шаг.

Главная кнопка `#mainBtn` стоит в потоке сразу под содержимым, а не у нижнего
края: внизу экрана на iPhone её перехватывает жест «домой». Не прибивать
кнопки к низу (`position:fixed; bottom`).
